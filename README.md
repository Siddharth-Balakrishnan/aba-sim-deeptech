# aba-sim-deeptech

## Overview

This repository implements a three‑part simulation pipeline for investigating deep‑tech student‑founder resource allocation. The pipeline consists of:

1. **ABM Data Generation** – an agent‑based model that creates synthetic student‑founder populations.
2. **NSGA‑II Multi‑Objective Optimisation** – searches for optimal resource allocation strategies.
3. **Elastic Net Machine‑Learning Analysis** – fits predictive models to understand key drivers of success.

The work follows a multiple‑basket cognitive framework to model the interplay between entrepreneurial intention, institutional support, and deep‑tech specific traits.
